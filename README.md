## Run it

1. Get a Session ID (`MONA-LISA:~…`) from the MONA LISA MD pairing site.
2. Copy `.env.example` to `.env` and fill in `SESSION_ID`.
3. `npm install --legacy-peer-deps && npm start`

The Session ID is a credential for your WhatsApp account. Never share it or commit it.

## Configuration

All identity values (name, owner, channel, group, session prefix) live in `lib/brand.js` and can be overridden
with environment variables — see `.env.example`.

## Updates

In-place self-update is disabled. Deployments run an immutable, versioned build; redeploy to update.
